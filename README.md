# Diplom_3

Дипломная работа Яндекс Практикума.
Автоматизация UI-тестирования приложения Stellar Burgers.

## Тесты проверяют

- Переход в раздел «Конструктор».
- Переход в раздел «Лента заказов».
- Открытие окна с деталями ингредиента.
- Закрытие окна с деталями ингредиента.
- Увеличение счётчика ингредиента при добавлении в заказ.
- Увеличение счётчика выполненных заказов за всё время.
- Увеличение счётчика выполненных заказов за сегодня.
- Появление номера заказа в разделе «В работе».
